# Variables, Data Types, Input/Output & Operators

## 📖 Overview

This section covers the fundamental building blocks of Java programming:

- Variables
- Primitive Data Types
- Input and Output
- Operators

These concepts form the foundation for all future Data Structures and Algorithms topics.

## 📂 Concepts Covered

### 1. Variables

Variables are containers used to store data values.

#### Examples:
- Integer variables
- String variables
- Boolean variables

#### Files:
- `Variables.java`

---

### 2. Data Types

Java provides several primitive data types:

| Data Type | Description |
|------------|------------|
| byte | Small integer |
| short | Medium integer |
| int | Standard integer |
| long | Large integer |
| float | Single precision decimal |
| double | Double precision decimal |
| char | Single character |
| boolean | true/false value |

#### Files:
- `DataTypes.java`

---

### 3. Input and Output

Used to interact with users through the console.

#### Topics Covered:
- `Scanner` class
- Reading integers
- Reading strings
- Printing output using `System.out.println()`

#### Files:
- `InputOutput.java`

---

### 4. Operators

Operators perform operations on variables and values.

#### Types Covered:

##### Arithmetic Operators
- `+` (Addition)
- `-` (Subtraction)
- `*` (Multiplication)
- `/` (Division)
- `%` (Modulus)

##### Relational Operators
- `==` (Equal To)
- `!=` (Not Equal To)
- `>` (Greater Than)
- `<` (Less Than)
- `>=` (Greater Than or Equal To)
- `<=` (Less Than or Equal To)

##### Logical Operators
- `&&` (AND)
- `||` (OR)
- `!` (NOT)

#### Files:
- `Operators.java`
